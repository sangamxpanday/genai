wikipedia retrievers

Vector Store retrievers
    most common type of retrievers
    fetch doc from vector store

    turns user query to vectore
    compares query with stored vectores

contexual compression retrievers
    advanced retriever that improves by compressing doc after retrieval
    normally, whole doc is retrieved but we need one sentence. 
    eg:
    retrieved doc = sangam is don. luffy is gonna be king of pirates. Lionel messi is goat of football
    query = who is monkey d. luffy
    then we get the whole doc but we need only second sentence. 
    we use normal retriever at first then send the retrieved doc to llm for compression/ trimming
    so in above example we get: luffy is gonna be king of pirates
    use when doc are large and has mixed information
